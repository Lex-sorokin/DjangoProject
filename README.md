# Проект интернет-магазина
## Описание проекта
Проект интернет-магазина создан с целью доработки и развития на протяжении всего курса. Проект будет включать в себя различные функции и возможности, которые будут реализованы на каждом уроке.

## Задания
### Задание 1. 
Настройка проекта.
Создать новую директорию для проекта.
Настроить виртуальное окружение.
Инициализировать новый проект Django.
Добавить файл .gitignore и правила ведения разработки по GitFlow.
Создать ветки main, develop и отдельные ветки для решения домашек.
Оформить файл README с описанием проекта.
### Задание 2. 
Создание и настройка приложения.
Создать новое приложение под названием catalog в проекте.
Зарегистрировать приложение в настройках проекта.
Настроить маршрутизацию для нового приложения.
### Задание 3. 
Создание шаблонов.
Подготовить два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
Использовать Bootstrap для стилизации страниц.
### Задание 4. 
Реализация контроллеров
Создать контроллер для отображения домашней страницы.
Создать контроллер для отображения страницы с контактной информацией.
Настроить маршрутизацию для этих контроллеров.
### Дополнительное задание.
Реализовать форму обратной связи на странице контактов.
Настроить обработку данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных.
